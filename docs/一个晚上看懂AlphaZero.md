凌晨六点半，训练脚本自己停了。单核跑了四个多小时，一千三百五十六局自博弈，最后留下一个十兆的权重文件。

它的水平说实话不太好听。跟一个完全乱走棋的程序下十二盘，赢八盘、和两盘、输两盘；跟一个只会"看见能吃的就吃、看见要吃我的就躲"的四十行小程序下六盘，一盘没赢；跟把棋力调到最低、每步只想二十毫秒的 Fairy-Stockfish 下四盘，同样一盘没赢。

但它确实变了。训练刚开始的时候，它会把马从 (1,0) 挪到 (1,1)，下一手再挪回来，来回晃到一百六十步判和；训练结束的时候，它会把车压到对方卒林线上抢子，丢了子也知道补。它学会的是"吃"，没学会"防"。

这篇文章讲的就是这中间发生了什么。代码在 `src/` 里，每节都会提到具体函数，想自己动手的话照着改就行。

## 它怎么决定下一步

轮到红方走，局面里通常有三十多个合法着法。搜索不会一次把每个着法都算清，它一趟一趟地走：先按网络给的印象挑一条看起来最值得看的线，一路走到底，碰到没展开的局面就让网络评价一下，再沿原路把评价退回去。退的时候每上一层换个符号，因为对我有利的局面，对对手就是不利的。

走一趟算一次模拟。一百六十趟走完之后，根节点下面每个着法旁边都攒了一个访问次数。被反复走的那几个，就是搜索认为有前途的；这个访问次数的分布，就是这一局要拿去训练网络的东西。

挑哪条线是有讲究的。每个子节点先算一个分数：拿它的历史评价取反（换成我的角度），再加上一项"网络觉得这里有希望、但还没怎么被走过"的奖励。前一项让它别把算力浪费在已经证实很差的着法上，后一项保证冷门着法也有机会被看。这套打分叫 PUCT，在 `mcts.py::select` 里。

## 网络学到的是什么

一局下完，我们把每一手的三样东西存进缓冲区：局面、搜索给出的访问次数分布、最后的胜负。然后训练网络同时做两件事，让策略头的输出接近那个分布，让价值头的输出接近最后的结果。

关键在于网络比搜索笨得多。搜索要算几万次节点才能得出的分布，网络得在几微秒里凭直觉给出一个差不多的。只要做得到，下一轮搜索的起点就更高；起点更高，算出来的分布又更准。这个循环转起来，就是"越下越好"的全部内容，没有别的魔法。

新网络不一定真的更强。学习率、噪声、样本偏差，随便哪个都能让它退步。所以每四十轮让新的挑战旧的，打十盘，胜率到百分之五十五才允许替换。`train.py::eval_vs_best` 做这件事，Leela Chess Zero 和 AlphaZero 原文里也是这么卡的。

## 单核上必须让掉的几件事

网络只能很小：十四张九乘十的特征图进，两个二百五十六维隐层，出来一个八千一百维的策略头和一个价值标量，一共约两百五十万参数。再大一点，单核推理一次就超过零点一毫秒，时间全花在网络上，搜索就没得算了。

每步只搜一百六十次。少了看不见"下一步被吃"，多了跑不完，这是这一夜里最贵也最敏感的参数。

策略目标只存访问次数前十六的着法。存全量的话缓冲区要三百倍大，内存撑不住，而且剩下的着法本来也没几次访问。

另外两个小决定：棋盘左右对称，每个局面顺手镜像一份，样本就翻倍；棋盘走到步数上限时按子力判胜负，这一条决定了这一夜能不能跑出结果，下一节说。

## 中途翻的三次车

第一版严格按论文来，只有把对方将死才算赢。跑出来二十六局里二十四局是和棋。两个都很弱的网络谁也杀不死谁，结果永远是零，价值头没有梯度可学，曲线从第一轮平到最后一轮。改法是加一条裁定：走满一百六十步，子力多的一方算赢。这一改对局立刻有了胜负，价值头也终于有事可做。代价是它变得贪子，不会为了长远攻势弃子换势。

第二版学不动，而且学坏了，具体表现是会来回挪马、白送车。查原因花了半小时，找到两个。一个是策略目标的概率加起来不是一：每步只存前十六个着法，剩下的概率被砍掉了，直接喂给交叉熵等于逼网络把总概率压到零点七。另一个更隐蔽，策略头有八千一百个输出，价值头只有一个，两边的梯度走同一个隐层主干，策略那边量级大得多，把表示冲掉了。我拿"价值输出和子力的相关性"当体检指标，热启动结束时是零点五四，训了十五轮之后掉到负零点零一，等于重新变成瞎猜。改法是每批重新归一化策略目标，策略损失乘零点一，学习率降到千分之一。

第三版能学了，但忘得快。缓冲区里只有自己最近几局的样本，几千条高度相关的数据，几十步梯度更新就能把刚学会的子力常识忘干净。改法是提前生成三千个"随机局面加子力标签"，每次训练掺三成进去，而且这些样本只训练价值头，不参与策略损失。价值头有了一个固定的锚，策略头该学什么还学什么。

还有一个教训跟深度有关。六十次模拟的时候，它会被乱走的对手白吃车，因为一层搜索看不见"下一步我要被吃"。加到一百六十次，对乱走对手的胜率从三成跳到九成。搜索是老师，老师自己不够强，教出来的东西也不会好。

## 这台机器的账

单核每秒大约跑两千到三千个搜索节点。一局按一百步、每步一百六十次模拟算，就是一万六千次节点展开，加上训练，八到十秒一局，一小时三百局上下。一夜五个多小时，一千三百局。

作为对照，AlphaZero 原文是四千四百万局、五千块 TPU、九小时。我们和它差了四个数量级。在这个量级上，学会规则、学会吃子、能赢乱走的，就是合理的天花板，指望它赢业余棋手不现实。

一夜跑完的账目：

| 项目 | 数值 |
|---|---|
| 用时 / 轮数 / 局数 | 4.7 小时 / 678 轮 / 1,356 局 |
| 策略损失 | 6.21 降到 2.20 |
| 价值损失 | 0.25 降到 0.19 |
| 对随机走子（12 局） | 8 胜 2 和 2 负 |
| 对一步贪心（6 局） | 0 胜 6 负 |
| 对 Stockfish Skill 0（4 局） | 0 胜 4 负 |
| 门控挑战 | 16 次里过了 5 次 |

策略损失降得很干净，说明它确实学会了模仿自己的搜索。但棋力曲线没怎么动，因为它在模仿的那个搜索本身没有变强。价值头学到的东西说到底就是子力差，而子力差看不见"我这匹马下一手会丢"。所以它能赢乱走的，输给任何愿意多看一眼威胁的对手，包括那个四十行的贪心程序。

## 想继续往上走

只有一条路划算：找 Fairy-Stockfish 当老师。让它标注二十万到五十万个局面，每步给出前几个候选和评估分，先让网络学会模仿一个真正的棋手，再拿这套自博弈循环微调。标注在本机大概半小时，蒸馏训练八分钟，之后叠上搜索，预计能到一千六百 Elo 左右，那时才谈得上"下得有来有回"。

把自博弈跑得更久不是办法。从一千三百局加到一万局，多出来的部分只会让它把"贪子"这件事学得更熟。

## 代码在哪

规则引擎是 `src/xiangqi.py`，perft 在 44 / 1,920 / 79,666 / 3,290,240 四个深度上全部对上权威值。现成的 `cchess` 库在这里是错的，少百分之五的合法着法，别用。

搜索在 `src/mcts.py`，网络和手写的反向传播在 `src/nn.py`，训练循环在 `src/train.py`。看板在 `web/index.html`，起 `src/serve.py` 之后能看到胜率、损失、局数和每一局回放；`web/play.html` 可以直接跟它对弈，点棋子再点目标格，右边会显示它这一步在考虑什么。`src/report.py` 负责曲线图和离线快照。
